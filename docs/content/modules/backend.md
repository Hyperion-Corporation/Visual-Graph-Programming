# Python Backend (`backend/`)

The intelligence sidecar: machine learning, optimization, and LLM integration.

**Responsibilities**

- Code embeddings stored on GrafeoDB graph nodes
- Graph-RAG retrieval (graph traversal ∪ vector ANN, RRF fusion)
- OR layout engine (stress majorization / MIP via OR-Tools)
- MCP server exposing graph tools to LLM agents
- Commit-to-commit semantic diffing
- PyInstaller-frozen sidecar for the Tauri app

**Build & test**

```bash
uv sync --all-extras
uv run pytest
uv run ruff check . && uv run mypy backend
```
