# Unreal Engine Plugin (`plugin/`)

Bidirectional C++ visual scripting inside the Unreal Editor
(roadmap Track C — scaffolding lands with step C1).

**Responsibilities**

- Custom `UEdGraph`/`UEdGraphNode` classes representing C++ constructs
- Slate presentation (`SGraphEditor` asset editor, Blueprint-styled nodes)
- Schema-enforced, type-checked pin validation
- Round-trip engineering via `tree-sitter-unreal-cpp` (lossless macro-aware
  parsing) and Live Coding integration
- Asset-registry dependency graphs and designer-facing logic-flow views

**Build**

Compile against the pinned engine version from a UE project embedding the
plugin; see `.agent/skills/build-and-test.md`.
