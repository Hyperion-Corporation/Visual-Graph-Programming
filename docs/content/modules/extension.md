# VS Code Extension (`extension/`)

In-editor graph visualization and navigation.

**Responsibilities**

- Webview graph panel (React Flow) with VS Code theme integration
- web-tree-sitter local AST extraction in the extension host
- LSP call-hierarchy graphs (incoming/outgoing)
- Bidirectional navigation: node ⇄ exact source line
- Semantic filtering, path extraction, Mermaid/PlantUML export

**Build & test**

```bash
npm install                       # repo root (workspaces)
npm run build:extension
npm run test --workspace=extension
```
