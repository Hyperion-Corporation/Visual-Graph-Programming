# C++ Base Core (`base/`)

The parsing/graph engine every frontend consumes.

**Responsibilities**

- Tree-sitter incremental parsing (C++, Python, TypeScript grammars)
- AST → code property graph extraction with byte-offset source anchors
- GrafeoDB ingestion (transactional, incrementally invalidated)
- Query surface: caller/callee traversals, inheritance chains, blast radius
- WebSocket/IPC server streaming viewport-scoped subgraphs
- Stable, versioned `extern "C"` API for host wrappers

**Build & test**

```bash
pixi run configure && pixi run build
pixi run test
```
