# Building the Documentation

The docs are a two-layer system:

1. **Per-module API references**, each generated by that module's native tool:

   | Module | Tool | Config | Output |
   | --- | --- | --- | --- |
   | `backend/` (Python) | Sphinx (autodoc + napoleon, Furo) | `docs/backend/conf.py` | `docs/_build/api/backend/` |
   | `base/` (C++) | Doxygen | `docs/base/Doxyfile` | `docs/_build/api/base/` |
   | `plugin/` (UE C++) | Doxygen | `docs/plugin/Doxyfile` | `docs/_build/api/plugin/` |
   | `extension/` (TS) | TypeDoc | `docs/extension/typedoc.json` | `docs/_build/api/extension/` |
   | `app/src` (TS) | TypeDoc | `docs/app/typedoc.json` | `docs/_build/api/app/` |
   | `app/src-tauri` (Rust) | rustdoc | — (`cargo doc`) | `docs/_build/api/rust/` |

2. **This MkDocs site** (`docs/mkdocs.yml`, Material theme), which provides
   the narrative documentation and links into the generated references. The
   build script copies the API outputs into `site/api/` so one static site
   contains everything.

## One-Command Build

```bash
bash docs/build_docs.sh          # builds everything available, skips missing modules
```

The script is tolerant by design: modules that aren't scaffolded yet (or
tools missing from your environment) are **skipped with a notice**, not
errors — so docs build cleanly at every stage of the roadmap.

Output: `docs/_build/site/` — open `docs/_build/site/index.html`.

## Per-Tool Commands

```bash
# Python API (Sphinx) — needs: uv sync --group docs
uv run sphinx-build -b html docs/backend docs/_build/api/backend

# C++ / plugin API (Doxygen) — provided by the pixi env
pixi run docs-base          # doxygen docs/base/Doxyfile
pixi run docs-plugin        # doxygen docs/plugin/Doxyfile

# TypeScript APIs (TypeDoc) — needs: npm install
npm run docs --workspace=extension
npm run docs --workspace=app

# Rust API (rustdoc)
cargo doc --no-deps -p vgp-app

# Narrative site only (fast preview with live reload)
uv run mkdocs serve -f docs/mkdocs.yml
```

## Dependency Wiring

- Python docs tools live in the `docs` dependency group of `pyproject.toml`
  (`uv sync --group docs`).
- Doxygen is a pixi dependency (`pixi install`).
- TypeDoc is a devDependency of each TypeScript workspace (`npm install`).
- rustdoc ships with the Rust toolchain.
