# docs/ — Documentation Toolchain

Two-layer documentation: per-module API references generated by each
module's native tool, unified under a MkDocs (Material) site.

```
docs/
├── mkdocs.yml           # umbrella site config (content in content/)
├── content/             # narrative pages (home, architecture, module guides)
├── backend/             # Sphinx config for the Python backend (conf.py, index.rst)
├── base/Doxyfile        # Doxygen config for the C++ core
├── plugin/Doxyfile      # Doxygen config for the Unreal Engine plugin
├── extension/typedoc.json  # TypeDoc config for the VS Code extension
├── app/typedoc.json     # TypeDoc config for the Tauri app UI
├── build_docs.sh        # one-command orchestrator (tolerant of missing modules)
└── _build/              # generated output (gitignored): api/<module>/ + site/
```

## Build Everything

```bash
uv sync --group docs     # Sphinx + MkDocs toolchain (once)
npm install              # TypeDoc via workspaces (once)
pixi install             # Doxygen (once)

bash docs/build_docs.sh  # or: npm run docs
# → open docs/_build/site/index.html
```

Rustdoc for `app/src-tauri` is included automatically (`cargo doc`).

See `content/building.md` (rendered on the site as *Building the Docs*) for
per-tool commands and how the pieces fit together.
